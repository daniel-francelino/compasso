## AiChatPage

`import { AiChatPage } from "@danielsoaresf/lost-ui/templates/ai-chat/ai-chat-page";`

A chat screen: the list of conversations at the side (a drawer on a phone), and the
conversation with its prompt. With no messages it welcomes the user and offers suggestions.
It fills its parent, so give the parent a height. The app owns the data: the conversations, the
messages and the status come in as props and the handlers say what the user did.

| Prop                 | Type                                                            | Default | Description                                                                    |
| -------------------- | --------------------------------------------------------------- | ------- | ------------------------------------------------------------------------------ |
| **onSend**           | `(text: string, files: File[]) => void`                         |         | Sends what the user wrote, with the files.                                     |
| conversations        | `AiChatConversation[]`                                          | `[]`    |                                                                                |
| activeConversationId | `string \| null`                                                | `null`  | The open conversation. `null` or nothing is a new chat.                        |
| onSelectConversation | `((id: string) => void)`                                        |         |                                                                                |
| onNewConversation    | `(() => void)`                                                  |         |                                                                                |
| onDeleteConversation | `((id: string) => void)`                                        |         | Adds a delete button to each conversation.                                     |
| messages             | `ChatMessageData[]`                                             | `[]`    |                                                                                |
| status               | `ChatStatus`                                                    | `ready` |                                                                                |
| onStop               | `(() => void)`                                                  |         |                                                                                |
| onReload             | `(() => void)`                                                  |         | Generates the last answer again; also the button of the prompt after an error. |
| title                | `ReactNode`                                                     |         | The title above the chat. Defaults to the title of the open conversation.      |
| headerActions        | `ReactNode`                                                     |         | Beside the title, at the end: a share button, a model picker.                  |
| welcomeTitle         | `ReactNode`                                                     |         | The heading of the empty chat.                                                 |
| welcomeDescription   | `ReactNode`                                                     |         |                                                                                |
| suggestions          | `(string \| ChatSuggestion)[]`                                  | `[]`    | Prompts shown in the empty chat.                                               |
| renderText           | `((text: string, context: ChatPartContext) => ReactNode)`       |         | Draws the text of the answers, e.g. with Markdown.                             |
| renderPart           | `((part: ChatPart, context: ChatPartContext) => ReactNode)`     |         |                                                                                |
| getActions           | `((message: ChatMessageData, isLast: boolean) => ChatAction[])` |         | Replaces the buttons under each answer (copy and regenerate).                  |
| note                 | `ReactNode`                                                     |         | Small print under the prompt, e.g. "The assistant can make mistakes."          |
| placeholder          | `string`                                                        |         |                                                                                |
| attachments          | `boolean`                                                       | `false` | Lets the user attach files.                                                    |
| accept               | `string`                                                        |         |                                                                                |

| className            | `string`                                                        |         |                                                                                |

## BackofficeLayout

`import { BackofficeLayout } from "@danielsoaresf/lost-ui/templates/backoffice/backoffice-layout";`

The whole internal layout of a backoffice from props: sidebar with the navigation and the user,
top bar with breadcrumbs, space switcher and notifications, the page, and the bottom bar on phones.
Everything it draws is also exported on its own, for an app that needs more control.

| Prop                 | Type                           | Default | Description                                                                                    |
| -------------------- | ------------------------------ | ------- | ---------------------------------------------------------------------------------------------- |
| **sections**         | `NavSection[]`                 |         | The navigation. `hidden` items and empty groups are left out; use `allow` for permissions.     |
| fullScreen           | `boolean`                      |         | Draws only the page, with no sidebar or bar, e.g. a point of sale or a preview.                |
| fullWidth            | `boolean`                      |         | Lets the page use the whole width instead of a centred column.                                 |
| overlay              | `ReactNode`                    |         | Shown over everything, e.g. a `Toaster` or an install banner.                                  |
| defaultSidebarOpen   | `boolean`                      |         |                                                                                                |
| transitionKey        | `string \| number`             |         | Animates the swap of the page when it changes, e.g. the pathname. Leave out for no transition. |
| className            | `string`                       |         |                                                                                                |
| allow                | `((item: NavItem) => boolean)` |         | Decides per item whether the user may see it, e.g. `(item) => can(user, item.permission)`.     |
| pathname             | `string`                       |         | The page now. Defaults to the address of the window.                                           |
| renderLink           | `RenderNavLink`                |         |                                                                                                |
| logo                 | `ReactNode`                    |         | The top of the sidebar: the logo, a team menu…                                                 |
| user                 | `BackofficeUser`               |         |                                                                                                |
| userItems            | `NavItem[]`                    |         | Links in the menu of the user, e.g. "My profile".                                              |
| onSignOut            | `(() => void)`                 |         |                                                                                                |
| breadcrumbs          | `TopbarCrumb[]`                |         | The path to the page, in the top bar.                                                          |
| spaces               | `Space[]`                      |         | The areas of the app, as a switcher in the top bar.                                            |
| currentSpace         | `string`                       |         |                                                                                                |
| unreadCount          | `number`                       |         | Unread notifications. Setting it (even to 0) shows the bell.                                   |
| notificationsHref    | `string`                       |         | Where the bell goes.                                                                           |
| onNotificationsClick | `(() => void)`                 |         |                                                                                                |
| topbarActions        | `ReactNode`                    |         | More in the end of the top bar.                                                                |
| bottomItems          | `NavItem[]`                    |         | The bottom bar of small screens. Leave out to have none.                                       |
| moreItems            | `NavItem[]`                    |         |                                                                                                |
| contextItems         | `NavItem[]`                    |         |                                                                                                |
