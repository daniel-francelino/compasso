## ButtonGroup

`import { ButtonGroup } from "@danielsoaresf/lost-ui/elements/button-group";`

Joins buttons, inputs, selects and badges into one control: the inner corners are squared and the
borders overlap. The counterpart of `FieldGroup` in Nuxt UI.

| Prop        | Type                                   | Default      | Description                                                                         |
| ----------- | -------------------------------------- | ------------ | ----------------------------------------------------------------------------------- |
| size        | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` |              | Height and text size of every control in the group. Leave it out to keep their own. |
| orientation | `"horizontal" \| "vertical"`           | `horizontal` |                                                                                     |

## PageTransition

`import { PageTransition } from "@danielsoaresf/lost-ui/elements/page-transition";`

Animates the swap of its content when `transitionKey` changes. It respects the "reduce motion"
setting of the system: with it on, the content changes with no movement.

| Prop              | Type                             | Default   | Description                                                                                                    |
| ----------------- | -------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------- |
| **transitionKey** | `string \| number`               |           | Changing it swaps the content: the old one goes out, then the new one comes in.                                |
| variant           | `"fade-up" \| "fade" \| "slide"` | `fade-up` | `fade-up` rises a little (a page); `fade` only fades (a panel); `slide` moves sideways, following `direction`… |
| direction         | `1 \| -1`                        | `1`       | For `slide`: 1 comes in from the right (next), -1 from the left (back).                                        |
| initial           | `boolean`                        | `false`   | Animates the first render too. By default only the changes are animated.                                       |
| className         | `string`                         |           |                                                                                                                |
