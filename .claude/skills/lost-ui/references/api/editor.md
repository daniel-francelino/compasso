## EditorBlockHandle

`import { EditorBlockHandle } from "lost-ui/editor/editor-block-handle";`

The grip beside each block: drag it to move the block, click it for the menu (turn into,
duplicate, delete), and the plus beside it adds a block below. Ctrl+/ (Cmd+/ on a Mac) opens the
same menu from the keyboard for the block that holds the cursor.

| Prop       | Type                             | Default | Description                                                                                       |
| ---------- | -------------------------------- | ------- | ------------------------------------------------------------------------------------------------- |
| **editor** | `Editor \| null`                 |         |                                                                                                   |
| turnInto   | `readonly EditorTurnIntoEntry[]` |         | The entries of "Turn into" (see `EditorBlockSpec.turnInto`). The built-in text blocks by default. |

## RichTextEditor

`import { RichTextEditor } from "lost-ui/editor/rich-text-editor";`

A block editor in the style of Notion: type `/` for blocks, select text for its formatting,
drag the grip to move a block. Headings, lists, tasks, quotes, code, tables, images, callouts and
toggles. It reads and writes HTML or the Tiptap JSON, takes your own blocks (`blocks`), and gives
you the Tiptap editor for the rest.

## RichTextView

`import { RichTextView } from "lost-ui/editor/rich-text-view";`

Shows the JSON of the editor without loading Tiptap: for a page that only reads the text, such as
a client portal. It draws what the editor writes, resolves image and file addresses with the same
functions, and drops what it does not know (unknown marks, unsafe links and colours).
