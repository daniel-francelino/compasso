## EventCalendar

`import { EventCalendar } from "@danielsoaresf/lost-ui/calendar/event-calendar";`

A calendar like Google Calendar: month, week and day views, previous / next / today, events of
several calendars that can be shown or hidden, and a click on an empty time to create an event.
It draws any kind of object (`events` + `accessors`), tells the app which days are on screen
(`onRangeChange`) and gives its own objects back. It fills its parent, so give the parent a
height. The app keeps the events, expands recurring ones and decides what a click does.

| Prop             | Type                                                                     | Default | Description                                                                                                    |
| ---------------- | ------------------------------------------------------------------------ | ------- | -------------------------------------------------------------------------------------------------------------- |
| **events**       | `T[]`                                                                    |         | Your own objects: tasks, appointments, posts, bookings. Say how to read them with `accessors`.                 |
| accessors        | `EventAccessors<T>`                                                      |         | Names the fields of `T` that give the id, title, start, end… Fields with the usual names need nothing.         |
| calendars        | `CalendarSource[]`                                                       |         |                                                                                                                |
| view             | `CalendarViewName`                                                       |         |                                                                                                                |
| defaultView      | `CalendarViewName`                                                       | `month` |                                                                                                                |
| onViewChange     | `((view: CalendarViewName) => void)`                                     |         |                                                                                                                |
| views            | `CalendarViewName[]`                                                     |         | The views of the switch, in order. One view hides the switch.                                                  |
| date             | `Date`                                                                   |         | The day shown; the month, week or day that has it.                                                             |
| defaultDate      | `Date`                                                                   |         |                                                                                                                |
| onDateChange     | `((date: Date) => void)`                                                 |         |                                                                                                                |
| onRangeChange    | `((range: CalendarVisibleRange) => void)`                                |         | Called with the days on screen whenever the view or the date changes, and once at the start, so the app can l… |
| weekStartsOn     | `WeekStart`                                                              | `0`     |                                                                                                                |
| locale           | `string`                                                                 |         | The `Intl` locale for dates and times, e.g. `"pt-BR"`. Defaults to the language of the library.                |
| hourHeight       | `number`                                                                 |         | Pixels per hour in the week and day views.                                                                     |
| scrollToHour     | `number`                                                                 |         | The hour the week and day views are scrolled to when they open.                                                |
| snap             | `number`                                                                 |         | The step, in minutes, a click on an empty time snaps to.                                                       |
| defaultDuration  | `number`                                                                 | `60`    | How long, in minutes, a new event is: for a click on the week and day views and for the New event button.      |
| maxMonthEvents   | `number`                                                                 |         | How many events a day of the month shows before "N more".                                                      |
| onEventClick     | `((event: T, mouse: MouseEvent<HTMLButtonElement, MouseEvent>) => void)` |         | Gets your own object back.                                                                                     |
| onCreate         | `((range: CalendarRange) => void)`                                       |         | The user picked a time or a day to create an event, by clicking an empty part or the "New event" button.       |
| onCalendarToggle | `((id: string) => void)`                                                 |         | A calendar was shown or hidden in the list. Adds the list at the side.                                         |
| onCalendarCreate | `(() => void)`                                                           |         | Adds a "new" button to the list of calendars.                                                                  |
| renderEvent      | `((event: T, color: string) => ReactNode)`                               |         | Draws an event its own way; gets your object and its colour.                                                   |
| actions          | `ReactNode`                                                              |         | Beside the "New event" button, at the end of the bar.                                                          |
| now              | `Date`                                                                   |         | The moment taken as "now". Without it the clock is used.                                                       |
| className        | `string`                                                                 |         |                                                                                                                |
