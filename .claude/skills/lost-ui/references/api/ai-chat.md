# API: ai-chat (`@danielsoaresf/lost-ui/ai-chat`)

Generated by `npm run skill` from the code. Only the props the component declares are listed; it also accepts the HTML attributes of its root element unless noted. Each folder has a story with working examples.

## ChatMessage

`import { ChatMessage } from "@danielsoaresf/lost-ui/ai-chat/chat-message";`

One message of the chat, as an `article`: the bubble, the avatar, the parts (text, reasoning,
tool calls, files, sources) and the actions that appear when you point at it.

| Prop       | Type                                                        | Default | Description                                                                                     |
| ---------- | ----------------------------------------------------------- | ------- | ----------------------------------------------------------------------------------------------- |
| **role**   | `ChatRole`                                                  |         |                                                                                                 |
| parts      | `ChatPart[]`                                                | `[]`    | The content, in the parts of the Vercel AI SDK `UIMessage`.                                     |
| streaming  | `boolean`                                                   | `false` | The message is the last one and its answer is still coming.                                     |
| variant    | `ChatMessageVariant`                                        |         | The bubble. By role: `soft` for the user, `naked` (no bubble) for the assistant.                |
| side       | `"left" \| "right"`                                         |         | `right` puts the message at the end of the line, up to 75% wide. By role: `right` for the user. |
| avatar     | `ReactNode`                                                 |         | An avatar or icon beside the message.                                                           |
| header     | `ReactNode`                                                 |         | Above the content: a name, a time.                                                              |
| actions    | `ChatAction[]`                                              |         | Buttons under the message, shown on hover and focus: copy, regenerate, rate.                    |
| compact    | `boolean`                                                   | `false` |                                                                                                 |
| renderText | `((text: string, context: ChatPartContext) => ReactNode)`   |         | Draws the text of a text part, e.g. with a Markdown renderer.                                   |
| renderPart | `((part: ChatPart, context: ChatPartContext) => ReactNode)` |         | Draws a part its own way. Return `undefined` to use the default.                                |
| className  | `string`                                                    |         |                                                                                                 |
| children   | `ReactNode`                                                 |         | Replaces the content of all the parts.                                                          |

## ChatMessages

`import { ChatMessages } from "@danielsoaresf/lost-ui/ai-chat/chat-messages";`

The conversation: the messages in a column that scrolls, a button to get back to the latest,
an indicator while the answer is awaited, and a footer for the prompt. It follows the answer as
it streams, unless the user scrolled up to read.

| Prop         | Type                                                            | Default | Description                                                                |
| ------------ | --------------------------------------------------------------- | ------- | -------------------------------------------------------------------------- |
| messages     | `ChatMessageData[]`                                             | `[]`    |                                                                            |
| status       | `ChatStatus`                                                    | `ready` | `submitted` shows the indicator while the answer has not started.          |
| autoScroll   | `boolean`                                                       | `true`  | Follows the answer as it grows, as long as the user has not scrolled up.   |
| scrollButton | `boolean`                                                       | `true`  | The button that goes back to the latest message when the user scrolled up. |
| indicator    | `ReactNode`                                                     |         | Replaces the dots-and-text shown while the answer has not started.         |
| user         | `RoleProps`                                                     |         | Props for the messages of the user: `variant`, `side`, `avatar`.           |
| assistant    | `RoleProps`                                                     |         | Props for the messages of the assistant: `variant`, `side`, `avatar`.      |
| compact      | `boolean`                                                       | `false` |                                                                            |
| getActions   | `((message: ChatMessageData, isLast: boolean) => ChatAction[])` |         | The buttons under each message, e.g. copy and regenerate.                  |
| renderText   | `((text: string, context: ChatPartContext) => ReactNode)`       |         |                                                                            |
| renderPart   | `((part: ChatPart, context: ChatPartContext) => ReactNode)`     |         |                                                                            |
| empty        | `ReactNode`                                                     |         | Shown when there are no messages: a welcome and some suggestions.          |
| footer       | `ReactNode`                                                     |         | Stays at the bottom, e.g. the prompt. The list leaves room for it.         |
| className    | `string`                                                        |         |                                                                            |
| children     | `ReactNode`                                                     |         | Messages drawn by hand, in place of `messages`.                            |

## ChatPrompt

`import { ChatPrompt } from "@danielsoaresf/lost-ui/ai-chat/chat-prompt";`

The box where the user writes to the assistant: a textarea that grows, send on `Enter`, files,
and the button that sends, stops or retries according to `status`.

| Prop          | Type                                       | Default   | Description                                                                                   |
| ------------- | ------------------------------------------ | --------- | --------------------------------------------------------------------------------------------- |
| value         | `string`                                   |           |                                                                                               |
| defaultValue  | `string`                                   | ``        |                                                                                               |
| onValueChange | `((value: string) => void)`                |           |                                                                                               |
| onSubmit      | `((value: string, files: File[]) => void)` |           | Called with the text and the files when the user sends. Empty text without files is not sent. |
| status        | `ChatStatus`                               | `ready`   | While `submitted` or `streaming` a second send is ignored and the button stops the answer.    |
| onStop        | `(() => void)`                             |           |                                                                                               |
| onReload      | `(() => void)`                             |           |                                                                                               |
| placeholder   | `string`                                   |           |                                                                                               |
| submitOnEnter | `boolean`                                  | `true`    | `Enter` sends and `Shift+Enter` breaks the line. With `false`, `Ctrl/Cmd+Enter` sends.        |
| maxRows       | `number`                                   | `8`       | The textarea grows with the text up to this many lines.                                       |
| autoFocus     | `boolean`                                  | `false`   |                                                                                               |
| disabled      | `boolean`                                  | `false`   |                                                                                               |
| attachments   | `boolean`                                  | `false`   | Adds the paperclip, and takes files pasted or dropped on the prompt.                          |
| accept        | `string`                                   |           | The types the file picker, the paste and the drop take, e.g. `"image/*,application/pdf"`.     |
| multiple      | `boolean`                                  | `true`    |                                                                                               |
| files         | `File[]`                                   |           |                                                                                               |
| onFilesChange | `((files: File[]) => void)`                |           |                                                                                               |
| variant       | `"outline" \| "soft" \| "naked"`           | `outline` |                                                                                               |
| header        | `ReactNode`                                |           | Above the textarea, e.g. a quote of the message being answered.                               |
| footer        | `ReactNode`                                |           | In the row under the textarea, beside the buttons: a model picker, tools.                     |
| submit        | `ReactNode`                                |           | Replaces the send button.                                                                     |
| onClose       | `(() => void)`                             |           | `Esc` was pressed in the textarea.                                                            |
| className     | `string`                                   |           |                                                                                               |

| Prop           | Type                        | Default | Description                                                                                   |

| onOpenChange   | `((open: boolean) => void)` |         |                                                                                               |
| className      | `string`                    |         |                                                                                               |

## ChatTool

`import { ChatTool } from "@danielsoaresf/lost-ui/ai-chat/chat-tool";`

A tool call of the assistant: its state in one line, and its output when you open it.

| Prop         | Type                        | Default  | Description                                                                 |
| ------------ | --------------------------- | -------- | --------------------------------------------------------------------------- |
| **text**     | `string`                    |          | What the tool does or did: "Searching components", "Lint checks completed". |

| open         | `boolean`                   |          |                                                                             |
| defaultOpen  | `boolean`                   | `false`  |                                                                             |
| onOpenChange | `((open: boolean) => void)` |          |                                                                             |
| actions      | `ReactNode`                 |          | Buttons under the label, e.g. "Approve" and "Deny".                         |
| className    | `string`                    |          |                                                                             |
