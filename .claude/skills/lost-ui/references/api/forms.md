## TimePickerPanel

`import { TimePickerPanel } from "lost-ui/forms/time-picker-panel";`

Picks a time of day from columns of buttons: hours, minutes, optional seconds, and AM or PM when
the locale uses a 12 hour clock. The value is `HH:mm[:ss]` on a 24 hour clock. A choice is made
with a click, Enter or Space; the arrows only move.

| Prop          | Type                        | Default | Description                                                                         |
| ------------- | --------------------------- | ------- | ----------------------------------------------------------------------------------- |
| value         | `string`                    |         | `HH:mm` or `HH:mm:ss`, on a 24 hour clock whatever is shown. Empty for no time yet. |
| onValueChange | `((value: string) => void)` |         |                                                                                     |
| seconds       | `boolean`                   | `false` | Adds a column of seconds, and `HH:mm:ss` values.                                    |
| hourCycle     | `12 \| 24`                  |         | 12 shows AM and PM. Defaults to what the locale uses.                               |
| minuteStep    | `number`                    | `1`     | Only every n-th minute is offered. Defaults to 1.                                   |
| secondStep    | `number`                    | `1`     | Only every n-th second is offered. Defaults to 1.                                   |
| min           | `string`                    |         | The earliest time that can be chosen, `HH:mm` or `HH:mm:ss`.                        |
| max           | `string`                    |         | The latest time that can be chosen, `HH:mm` or `HH:mm:ss`.                          |
| locale        | `string`                    |         |                                                                                     |
| label         | `string`                    |         | Names the panel for screen readers. Defaults to the translated "Time".              |
| showNow       | `boolean`                   | `true`  | Shows a Now button. Defaults to `true`.                                             |
| disabled      | `boolean`                   | `false` | Locks every button: nothing can be chosen, and none is reachable with Tab.          |
| onDone        | `(() => void)`              |         | Shows a Done button that calls this. Without it there is no Done button.            |
| className     | `string`                    |         |                                                                                     |
