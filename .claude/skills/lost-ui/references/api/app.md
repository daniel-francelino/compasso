# API: app (`@danielsoaresf/lost-ui/app`)

Generated by `npm run skill` from the code. Only the props the component declares are listed; it also accepts the HTML attributes of its root element unless noted. Each folder has a story with working examples.

## App

`import { App } from "@danielsoaresf/lost-ui/app/app";`

Put it once at the root. It sets the language of the components, the tooltips and the toasts for
the whole app, so `toast.success(…)` works anywhere below it.

| Prop      | Type                                                                     | Default | Description                                                           |
| --------- | ------------------------------------------------------------------------ | ------- | --------------------------------------------------------------------- |
| language  | `string`                                                                 |         | Language of the texts the components bring: `"en"`, `"es"` or `"pt"`. |
| tooltip   | `{ delayDuration?: number; skipDelayDuration?: number; disableHoverabl…` |         | Options of the tooltips of the whole app.                             |
| toaster   | `ToasterProps \| null`                                                   |         | Options of the `Toaster`, or `null` to leave it out.                  |
| dir       | `"ltr" \| "rtl"`                                                         |         | Reading direction of the whole app.                                   |
| dark      | `boolean`                                                                | `false` | Uses the dark values of the theme.                                    |
| className | `string`                                                                 |         |                                                                       |

## AppShell

`import { AppShell } from "@danielsoaresf/lost-ui/app/app-shell";`

The frame of the internal screens of an app: sidebar, top bar, the page and, on small screens,
a bottom bar. It brings a link that skips to the page and a focusable page for keyboards.

| Prop                | Type                                                                     | Default        | Description                                                                                    |
| ------------------- | ------------------------------------------------------------------------ | -------------- | ---------------------------------------------------------------------------------------------- |

| topbar              | `ReactNode`                                                              |                | The `AppTopbar`.                                                                               |
| bottomNav           | `ReactNode`                                                              |                | The `BottomNav`. The page leaves room for it on small screens.                                 |
| fullScreen          | `boolean`                                                                | `false`        | Draws only the page, with no sidebar or bar, e.g. a point of sale or a preview.                |
| fullWidth           | `boolean`                                                                | `false`        | Lets the page use the whole width instead of a centred column.                                 |
| defaultSidebarOpen  | `boolean`                                                                |                |                                                                                                |
| sidebarOpen         | `boolean`                                                                |                |                                                                                                |
| onSidebarOpenChange | `((open: boolean) => void)`                                              |                |                                                                                                |
| overlay             | `ReactNode`                                                              |                | Shown over everything, e.g. a `Toaster` or an install banner.                                  |
| mainId              | `string`                                                                 | `main-content` | Id of the page, the target of the skip link.                                                   |
| mainProps           | `Omit<DetailedHTMLProps<HTMLAttributes<HTMLElement>, HTMLElement>, "id…` |                |                                                                                                |

## AppSidebar

`import { AppSidebar } from "@danielsoaresf/lost-ui/app/app-sidebar";`

The side navigation of an app: groups of links, with sub-menus, badges and the active page marked.
It collapses to icons, becomes a sheet on small screens and closes itself when a link is followed.
Put it inside an `AppShell` (or a `SidebarProvider`).

| Prop         | Type                                 | Default                          | Description                                                                   |
| ------------ | ------------------------------------ | -------------------------------- | ----------------------------------------------------------------------------- |
| **sections** | `NavSection[]`                       |                                  |                                                                               |
| side         | `"left" \| "right"`                  |                                  |                                                                               |
| variant      | `"sidebar" \| "floating" \| "inset"` |                                  |                                                                               |
| collapsible  | `"offcanvas" \| "icon" \| "none"`    | `icon`                           |                                                                               |
| pathname     | `string`                             |                                  | The page now, to mark the active item. Defaults to the address of the window. |
| header       | `ReactNode`                          |                                  | Top of the sidebar, e.g. the logo or a team menu.                             |
| footer       | `ReactNode`                          |                                  | Bottom of the sidebar, e.g. the `UserMenu`.                                   |
| renderLink   | `RenderNavLink`                      | `({ item: _item, href, childre…` | Draws the link of an item with the router of the app.                         |
| onNavigate   | `((item: NavItem) => void)`          |                                  | Called when an item is chosen. The sidebar of small screens closes by itself. |
| rail         | `boolean`                            | `true`                           | Shows the strip that opens and closes the sidebar.                            |

## BottomNav

`import { BottomNav } from "@danielsoaresf/lost-ui/app/bottom-nav";`

The navigation of small screens: a bar fixed at the bottom with the main destinations, a "More" menu

| contextItems | `NavItem[]`     | `[]`                             | Replaces `items` while there are some, e.g. the tabs of the page that is open (inbox, sent, drafts). An item … |

| renderLink   | `RenderNavLink` | `({ item: _item, href, childre…` |                                                                                                                |

## Theme

`import { Theme } from "@danielsoaresf/lost-ui/app/theme";`

Re-themes a part of the page. The colours and the radius are CSS variables, so every component
inside follows them with no prop. Nest blocks to refine: the inner one wins and the rest is inherited.
It does not set the props of the components, which Nuxt UI's `Theme` can.

| Prop      | Type                     | Default | Description                                                                                                    |
| --------- | ------------------------ | ------- | -------------------------------------------------------------------------------------------------------------- |
| tokens    | `Record<string, string>` |         | Values for the tokens of the theme inside this block, by name: `{ primary: "oklch(0.6 0.2 260)" }` sets `--pr… |
| radius    | `string`                 |         | Sets `--radius`.                                                                                               |
| dark      | `boolean`                | `false` | Uses the dark values of the theme inside this block, whatever the page uses.                                   |
| as        | `ElementType`            | `div`   |                                                                                                                |
| className | `string`                 |         |                                                                                                                |
