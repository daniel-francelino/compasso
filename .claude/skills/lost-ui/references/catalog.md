# Catalog

Every folder is importable as `@danielsoaresf/lost-ui/<layer>/<folder>`; the layer entry (`@danielsoaresf/lost-ui/<layer>`) exports all of them except the ones noted. Generated by `npm run skill`; the props of each component are in `api/<layer>.md`.

## ui (`@danielsoaresf/lost-ui/ui`)

shadcn primitives, upstream shape (props are the Radix and HTML ones). Peers by path: calendar, carousel, command, drawer, form, input-otp, resizable, sonner.

`accordion`, `alert`, `alert-dialog`, `aspect-ratio`, `avatar`, `badge`, `breadcrumb`, `button`, `calendar`, `card`, `carousel`, `checkbox`, `collapsible`, `command`, `context-menu`, `dialog`, `drawer`, `dropdown-menu`, `form`, `hover-card`, `input`, `input-otp`, `label`, `menubar`, `navigation-menu`, `pagination`, `popover`, `progress`, `radio-group`, `resizable`, `scroll-area`, `select`, `separator`, `sheet`, `skeleton`, `slider`, `sonner`, `switch`, `table`, `tabs`, `textarea`, `toggle`, `toggle-group`, `tooltip`

## elements (`@danielsoaresf/lost-ui/elements`)

small pieces made of primitives.

`avatar-group`, `button-group`, `chip`, `kbd`, `link`, `modal`, `page-transition`, `progress-group`, `slideover`, `stepper`

## app (`@danielsoaresf/lost-ui/app`)

the frame of an app. `app` needs `sonner` and is imported by path (`@danielsoaresf/lost-ui/app/app`). `app-nav` has the `NavItem` types and helpers, no component.

`app`, `app-nav`, `app-shell`, `app-sidebar`, `app-topbar`, `banner`, `bottom-nav`, `container`, `error-page`, `footer`, `footer-columns`, `header`, `main`, `notification-button`, `notification-item`, `notification-preferences`, `page-header`, `settings-section`, `sidebar`, `space-switcher`, `theme`, `user-menu`

## ai-chat (`@danielsoaresf/lost-ui/ai-chat`)

the pieces of an AI chat screen. No SDK needed: messages have the shape of the Vercel AI SDK `UIMessage`, so `useChat().messages` goes in as it is. See `references/ai-chat.md`.

`chat-attachment`, `chat-message`, `chat-messages`, `chat-palette`, `chat-parts`, `chat-prompt`, `chat-prompt-submit`, `chat-reasoning`, `chat-shimmer`, `chat-suggestions`, `chat-tool`

## editor (`@danielsoaresf/lost-ui/editor`)

a Notion-style block editor on Tiptap (`/` menu, selection toolbar, block handle, tables, tasks, callouts, toggles). Needs the Tiptap peers; see `references/editor.md`.

`editor-block-handle`, `editor-bubble-menu`, `editor-slash-menu`, `editor-table-bar`, `rich-text-editor`

## calendar (`@danielsoaresf/lost-ui/calendar`)

month, week and day views of events (`EventCalendar` is the whole screen), a list of calendars to show or hide, and the date helpers. No peers. See `references/calendar.md`.

`calendar-date-nav`, `calendar-event-chip`, `calendar-list`, `calendar-model`, `day-view`, `event-calendar`, `month-view`, `time-grid`, `week-view`

## forms (`@danielsoaresf/lost-ui/forms`)

`form-input-date`, `form-pin-input`, `form-input-phone`, `form-country-select`, `form-emoji-picker` and `form-builder` need optional peers and are imported by path.

`form`, `form-builder`, `form-checkbox`, `form-checkbox-group`, `form-color-picker`, `form-country-select`, `form-emoji-picker`, `form-field`, `form-fieldset`, `form-file-upload`, `form-input`, `form-input-date`, `form-input-menu`, `form-input-money`, `form-input-number`, `form-input-password`, `form-input-phone`, `form-input-rating`, `form-input-tags`, `form-input-time`, `form-listbox`, `form-option-list`, `form-pin-input`, `form-radio-group`, `form-select`, `form-select-menu`, `form-slider`, `form-switch`, `form-textarea`, `rules`

## data (`@danielsoaresf/lost-ui/data`)

data display.

`data-table`, `data-table-column-toggle`, `data-table-pagination`, `data-table-row-actions`, `empty`, `timeline`, `tree-view`, `user-info`

## charts (`@danielsoaresf/lost-ui/charts`)

`*-chart` are the data-driven ones; the other folders are the pieces they are made of.

`area-chart`, `bar-chart`, `chart-center-label`, `chart-container`, `chart-legend`, `chart-legend-content`, `chart-series`, `chart-style`, `chart-tooltip`, `chart-tooltip-content`, `line-chart`, `pie-chart`, `radar-chart`, `radial-chart`

## templates (`@danielsoaresf/lost-ui/templates`)

pages and layouts reused between projects, grouped by category (`auth`, `errors`, `backoffice`): import `@danielsoaresf/lost-ui/templates/<category>/<folder>`. `lib` holds helpers, not for import.

`ai-chat/ai-chat-page`, `auth/auth-layout`, `auth/auth-message-page`, `auth/forgot-password-page`, `auth/login-page`, `auth/register-page`, `auth/reset-password-page`, `backoffice/backoffice-layout`, `backoffice/notifications-page`, `backoffice/profile-page`, `backoffice/settings-index-page`, `backoffice/settings-layout`, `errors/error-fallback`, `errors/forbidden-page`, `errors/not-found-page`

## effects (`@danielsoaresf/lost-ui/effects`)

79 landing-page animations from Magic UI (marquee, globe, confetti, blur-fade, number-ticker…). Names, paths and optional peers: the library's `docs/effects-inventory.md`.

## i18n (`@danielsoaresf/lost-ui/i18n`)

`LostI18nProvider`, `useLostTranslation`, `translate`, `registerMessages`, `lostI18n`.
